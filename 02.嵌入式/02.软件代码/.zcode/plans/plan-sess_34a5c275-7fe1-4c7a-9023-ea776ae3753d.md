## 目标

软件静止自校准：板子静止时在线跟踪陀螺零偏，抑制 yaw 漂移。原理——静止时三轴角速度的窗口均值就是残余零偏，指数平滑后从原始 gyro 中扣除；晃动时漂移重新累积，但再次静止会自动收敛。**不改硬件、不改协议、不动电机链路。**

## 原理与边界

- 当前 yaw = 纯陀螺积分（加速度计感知不到绕重力轴的旋转），漂移来自残余零偏/温度。静止自校准把这些残余**动态扣掉**，静止时 yaw 漂移收敛到近零。
- 局限（写进注释/文档）：晃动期间 yaw 仍会累积漂移；这不是"绝对航向"（那需要磁力计，板上没有且无空闲引脚）。
- 对单轴 pitch 云台无实际影响（pitch 被重力钳住，yaw 不参与闭环），纯改善调试体验。

## 改动清单

### 1. 新增 `BSP/gyro_bias.c/.h`（小型独立模块，风格对齐 pid/filter）
- `gyro_bias_t { threshold, window, gain, cap, count, sum[3], runtime[3] }`
- `gyro_bias_init()`：置零 runtime、装入参数
- `gyro_bias_update(raw_gyro[3])`：任一角速度超 threshold → 计数清零；连续 window 个样本静止 → `runtime[i] += (mean[i]-runtime[i])*gain`（|mean|>cap 则跳过），返回是否更新
- `gyro_bias_reset()`：清计数/求和（保留 runtime，防 sensor_lost 后误清已收敛值？——不，sensor_lost 期间数据不可信，runtime 也清零，重新收敛）

### 2. `App/gimbal_app.c`（控制环接线）
- 新增 static `gyro_bias_t s_bias`
- `gimbal_app_init()` 调 `gyro_bias_init(&s_bias, APP_BIAS_* 常量)`
- `gimbal_app_control_step()` 中，成功读样后：
  1. `gyro_bias_update(&s_bias, sample.gyro)`（输入为驱动已扣 boot 零偏的原始值）
  2. `corrected[i] = sample.gyro[i] - s_bias.runtime[i]`
  3. `imu_fusion_update(dt, corrected, sample.accel)`（原传 sample.gyro → 改 corrected）
  4. 遥测 `gyro[3]` 存 corrected；新增 `gyro_bias[3]` 存 runtime（供诊断）
- 仅 state==RUNNING 时执行；SENSOR_LOST 恢复转换处调 `gyro_bias_reset()`

### 3. `App/gimbal_app.h`
- `gimbal_telemetry_t` 增加 `float gyro_bias[3]`（rad/s，运行零偏）

### 4. `App/app_config.h`（常量，附注释）
- `APP_BIAS_THRESHOLD_RAD_S 0.03f`（≈1.7°/s，静止判据）
- `APP_BIAS_WINDOW_SAMPLES 500u`（0.5s @1kHz 静止窗口）
- `APP_BIAS_GAIN 0.2f`（每次窗口折 20%，约 2-3s 收敛大半）
- `APP_BIAS_CAP_RAD_S 0.5f`（防误判锁定离谱值）

### 5. `App/app_tasks.c` 诊断行
- 追加 `bias=%.3f`（三轴 runtime 的最大绝对值），验证收敛用

### 6. 工程/文档
- 重跑 patch：BSP 组追加 `../BSP/gyro_bias.c`；README 构建命令同步
- README 功能描述 + Known limitations 补一句"静止自校准可抑制 yaw 漂移，晃动期仍累积（IMU-only 物理限制）"；BRINGUP.md 增补验证节

## 验证

1. UV4 构建 0 Error 0 Warning；协议回归
2. **真机验证（板子在 COM3）**：
   - openocd 烧录 → 板子静置 → dump 串口 15-20s
   - 判定：yaw 漂移速率在 3-5s 后趋近 ~0（对比校准前后 yaw 变化量）；`bias=` 从 0 收敛到小稳定值
   - 若用户在场可晃动板子再静置，确认再次收敛
3. 无需改 att_viewer（ATT 行格式不变）

## 不做

- 不加磁力计（板上无芯片、无空闲 I2C、需磁校准）
- 不改 20B 协议/电机链路/USART3 遥测
- 不承诺晃动期 yaw 不漂（物理不可行）
