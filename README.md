- **设计亮点**：针对高爆发射击需求重新设计了供电线路与铜皮载流截面，**支持四路 3S 无刷电机单路持续稳定输出约 8A 电流（单路 8A，总载流达 30A+ 级别）**，彻底解决原版在大功率摩擦轮连续加速下电压跌落、发热严重的问题，为摩擦轮高速连发提供充沛动力源。

## 🛠️ 本次二次开发（二改）核心改动与优化

### 1. 无线通信广播帧精简重构（方案 A：13字节紧凑帧）
- **剔除 7 字节冗余零占位符**：将原版 20 字节（底层 32 字节 Payload）精简收紧至 13 字节紧凑报文；
- **空中传输时间降低 58%**：NRF24L01 空中耗时从 260微秒 骤降至 110微秒，在电磁干扰强烈的竞技赛场上显著提升抗冲突与防丢包能力，降低遥控延迟。

### 2. 硬件电路重构与传感器降本
- **自研大电流分电板**：支持单路 8A（四路总电流 30A+），专为大功率摩擦轮连发供电设计；
- **底盘主控 IMU**：原版昂贵的 BMI088 -> 替换为性价比更高、更易采购的 **BMI270**（兼容 IMU660RA / IST8310 驱动）；
- **云台主控 IMU**：原版 BMI088 -> 替换为更紧凑低成本的 **BMI055**，并重新适配姿态解算滤波算法。

### 3. 嵌入式软件与硬件适配优化
- **4310 FOC 云台闭环控制优化**：
  - **余弦重力前馈补偿（Pitch 轴）**：根据枪管实时物理俯仰角动态注入重力抗下垂电压，消除枪管下垂静差，实现全行程无静差悬停；
  - **1.0度安全死区软限位**：在机械物理死挡两端自动内缩 1.0度安全缓冲（活动区间 -25.45度 ~ +23.70度），彻底防止遥控器打死时撞击死挡；
  - **DMA 防数据撕裂机制（Yaw 轴）**：回发角度数据时避开 DMA 读取窗口，杜绝零度跨越点高低字节撕裂引起的云台力矩冲击；
  - **通信与断电看门狗**：具备丢包超时自动切断 PWM 保护、编码器掉线保护、过流闭锁与零点软捕获（开机不猛甩）。
- **发射机构走线优化**：
  - **激光迁移到发射机构板 PB6，方便走线**，并支持通过遥控器 KEY2 (PA4) 按键独立自锁开关控制。
- **灯条主控装甲板受击反馈修复**：
  - 严格对齐 4 块装甲板灯带与受击检测引脚硬件映射，修复了主循环 DMA 频繁打断导致的显示异常，实现精准受击变红闪烁与红蓝阵营一键切换。

## ⚡ 13 字节精简无线控制广播帧定义（方案 A）

全车各控制板（遥控器、底盘、云台、发射机构、灯控板）统一采用 13 字节紧凑报文：

| 字节偏移 | 字段定义 | 数据类型 | 控制说明 |
| :---: | :--- | :---: | :--- |
| **Byte 0** | 帧头 | uint8_t (0x55) | 帧同步头 |
| **Byte 1** | 按键掩码 (Key Mask) | uint8_t | KEY1 底盘模式 / KEY2 激光 / KEY4 阵营 / KEY5/6 供弹退弹 |
| **Byte 2** | 左旋钮 (Encoder_L) | int8_t | 底盘小陀螺自旋转速调节 |
| **Byte 3** | 右旋钮 (Encoder_R) | int8_t | 双/四摩擦轮无刷电机启停与调速 |
| **Byte 4..5** | 左摇杆水平 (LX) | int16_t | 云台 Yaw 轴旋转角度积分量 |
| **Byte 6..7** | 左摇杆垂直 (LY) | int16_t | 枪管 Pitch 轴俯仰角度积分量 |
| **Byte 8..9** | 右摇杆水平 (RX) | int16_t | 底盘左右平移速度 Vx |
| **Byte 10..11**| 右摇杆垂直 (RY) | int16_t | 底盘前后平移速度 Vy |
| **Byte 12** | 帧尾 | uint8_t (0xFF) | 13 字节紧凑帧结束校验 |
